# S-0406 claim ledger (building placement)

Revision 2. Claim 3 (b) now leaves listing to S-0209 claim 13 (a landed aircraft is listed and refuses, an aircraft in ordinary flight is not listed and does not), and claim 3 (d) names the bridge-body mark of S-0010 claim 25. No code change: the object test walks the cell's listed objects (claim 3 b, so a landed aircraft refuses) and the ground test reads the deck and bridge-body marks (`bridge_marked`). Ordinary flight cannot happen yet (aircraft stand landed; flight is a seam), so the not-blocking half of claim 3 (b) has no test.
