State and save: `income_restart` is saved with the object and hashed (`income_state_is_saved_and_hashed`:
the round trip hashes alike, the run goes on alike, the field changes the hash). The countdown stores
the tick of its last restart; its length is the type's delay, so the remaining time is derived.

Importer: the three cash keys are integers on a building type, absent reads 0, a later layer that omits
one keeps the value in force (`cash_keys_of_a_building_type`); the other keys of the Import mapping were
read by earlier specs (`NeedsEngineer`, `MultiplayPassive`, `SuperWeapon`, `SecretLab`, the self-heal counts)
or by the audio crate (`CaptureEvaEvent`).

Quirk switches: `cash_cycle_one_short` and `cash_cycle_lapse`, both consulted (`structures::tech::turn`),
both tested in both positions.

Own AI: `glasnost_ai::tech_buildings` ranks the engineer targets (a tech building held by a passive house
that pays, then the other tech buildings, then the rest), and the house orders an engineer when it sees such
a building (`Uses::tech` counts the orders; the runner prints "tech buildings").

Open questions of the spec: whether an unmanned outpost repairs vehicles (S-0314 claim 6) is not decided by
the spec; the repair stays as S-0314 builds it. Whether a passive house holds superweapon records for the
airports it owns is S-0512's.
