# S-0506 Missiles: claim ledger (M6a)

Code: `glasnost_sim::spawn`, `glasnost_sim::rocket`, `glasnost_sim::combat::flying`, with hooks in
`combat::{area, check, death, fire, veterancy, weapon, behave, acquire}`, `drive`, `targeting`,
`objects` and `tick`. Import: `glasnost_convert` (spawn keys, rocket sets, aircraft trailer).
Tests: `crates/deterministic/sim/tests/claims_s0506.rs` (48 tests); claim 1's creation order in `claims_creation_set.rs`.

Revision 11 (taken in after M7b, [step1g-m7b.md](../m7-claims/step1g-m7b.md)): claim 1 adds the creation draws and numbers of the initial slot objects and their order (S-0611 claim 14 and F5); scenario R1 gains the creation-set variants.

Status: **tested** (a test checks it), **partly** (built, and only some cases are tested or some
cases are seams), **seam** (an entry point exists, and the behaviour waits on another lane),
**not implemented**.

## End-to-end runs

- Set A: `set_a_launcher_attacks_in_play`. A launcher is ordered through
  `glasnost_sim::targeting::click`, launches, flies, detonates at the aim point and damages the
  target.
- Set B: `set_b_launcher_attacks_in_play`. A two-slot launcher stands in for a Dreadnought-like
  vessel. It uses the driving locomotor, because the ship locomotor (`naval.rs`) is still a
  scaffold.
