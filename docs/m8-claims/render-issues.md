# Rendering audit issues: ledger

The lead's audit of the rendering code at 4f55f4c3, filed as GitHub issues #66 to #153 and tracked in #154. Each batch has its own section, with one row per issue: fixed (with its tests), partly done, not reproduced or won't fix. No row changes what the simulation computes. The save format (127), the AI game format (93), the wire version (12) and the sim and AI goldens are unchanged.
