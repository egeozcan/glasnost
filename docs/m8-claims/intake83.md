# S-0102 r41: claim ledger, M8 step A3 intake 83

Intake 78 built S-0102 r34 ([intake78.md](intake78.md)). This intake builds r34 to r41. The delta
was read in full (`git diff 8dc8239 9a84bea -- spec/rendering/S-0102-draw-order.md`). It answers
**Q-2346**, which intake 78 filed with an interim rule. That interim is retired.

Requests filed: none. Q-2406 to Q-2415 are unused. The one part r41 leaves open, a member that
moves from one bridge deck to another, is in S-0102's own Open questions with its settling
scenario, so no request is filed for it (see claim 3 below).

**Client only.** The code changes are in `crates/app` only (`mapview::layers`, `mapview::live`).
No simulation code, rules, saved or hashed state changes, so the save format (93) and the AI game
format (56) stay the same, no golden moves and no simulation lane is due. No quirk switch is
added. The text of the existing `quirks.layer_change_on_events_only` grows a warp-member part,
built here with both positions tested. Its C7 verdict is in
[c7-play-fixes.md](c7-play-fixes.md) under *Intake 83*.

Status words: **tested** (built and checked by the named test), **partly** (the part named is
untested or not built), **seam** (built by another intake's spec; the reason is given), **no
change** (the revision restates what is built).
