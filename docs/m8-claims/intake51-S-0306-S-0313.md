# S-0306 r45, S-0313 r37: claim ledger, M8 step A3 intake 51

This intake takes in two revisions (spec commits ee49935 and 221622e). Together they answer
**Q-2111**, the request that [a6-arena-triage.md](a6-arena-triage.md) row 1 filed for DISK
against APOC (M-0001):

- **S-0306 r45** (projectiles) answers questions 1 and 4. Claim 8 now places a projectile at its
  *start point*. When the fire point (or claim 5's start position) is not above the terrain at its
  *x* and *y*, the start point is 1 lepton above that terrain, at the same *x* and *y*. A bridge
  deck there is ignored. So a steering projectile fired from a muzzle at the surface starts at
  height 1, and T1's *h* ≤ 0 row no longer detonates it in its first turn. The raise applies to
  every placed projectile: shots, fragments, airburst children and superweapon payloads. It does
  not apply to the later move of an invisible projectile (claim 9). Claims 5 to 7 (direction,
  pitch, velocity) and the line-of-fire walk's *X*₁ (claim 22) keep the unraised point. T1's Ω is
  measured from the start point. The new scenario P43 covers this, and the spec asks S-0318
  claim 5 to say the same for fragments.
- **S-0313 r37** (firing positions) answers question 2. Under claim 1a, an absent non-elite
  muzzle position is 0, 0, 0, with nothing taken from the other slot or the alternate muzzle
  positions. An absent elite muzzle position takes the same slot's non-elite one, as imported, and
  for numbered weapons elite weapon *n* takes weapon *n*'s. The Import mapping rows change to
  match. P1 has new parts d and e.
- Question 3 (which weapon hits the discs, and how hard) is left open in S-0306's Open questions.

No quirk comes with either revision.

## Built

- **`combat::projectile::start_point(w, p)`** (new, public) gives claim 8's start point. It uses
  `World::surface_at` (terrain only, no deck). Its callers are:
  - `projectile::launch` (shots, including dropping projectiles from the firer's position);
  - `projectile::airburst_children` (the nine projectiles an airburst releases);
  - `shrapnel::burst` (fragments, S-0318 claim 5);
  - `superweapons::nuke::missile` (the upward and downward missiles).
- **What the raise does not change.** Each projectile keeps its unraised point in
  `Projectile::fire_point`, which is the walk's *X*₁ (claim 22, in flight `x1`, and claim 9's
  walk for invisible projectiles). The direction, pitch and velocity of claims 5 to 7 are worked
  out from the unraised point before placement. `placed_at` and `omega` take the start point. An
  invisible projectile is still moved to *K*, or to the first blocking cell's centre at surface
  height, after placement, without a raise.
- **Muzzle-position table** (`combat::data::type_combat`). `flh` starts at 0, 0, 0. `elite_flh`
  starts as a copy of `flh` and is then overwritten by the elite keys given. Before this change,
  an elite numbered weapon past the end of the elite list, or for a type with no elite numbered
  keys, at slots 2 and above, got 0, 0, 0 instead of weapon *n*'s position.
- **Importer** (`convert::sim_combat`). `weapon_flh` is written up to the last `Weapon`*n*`FLH`
  given, with 0, 0, 0 for any gap. `elite_weapon_flh` is written up to the last elite key given,
  and an absent elite entry takes the same weapon's non-elite position (the Import mapping's
  "as imported"). `ElitePrimaryFireFLH` and `EliteSecondaryFireFLH` stay absent when not given,
  and the simulation applies claim 1a to them.
- **Formats.** No state was added, so the save format stays 88 and the AI game format stays 50.

## Design choices

| question | our choice |
|---|---|
| A type with numbered weapons and no `Weapon`*n*`FLH` key; a type of any turret count with one (Q-2146) | Kept from before. With no numbered key, slots 0 and 1 read `PrimaryFireFLH` and `SecondaryFireFLH`, and the elite pair when there are no elite numbered keys. Once a numbered key is given, only numbered keys count for the non-elite slots. No reference type has numbered weapons without numbered keys (local-lane count). **Q-2146 answered by S-0313 r42** (claim 1b: the turret count after each type read's rules section picks one family, numbered fields above 0, the primary and secondary pair at 0 or less), built in [intake 55a](intake55a-S-0301-S-0312-S-0313-S-0303-S-0318-M-0004.md); the interim is replaced |
| An elite object whose elite slot holds no weapon (S-0313's new Open question) | The elite slot's own muzzle position, as claim 1a gives it (`combat::position::fire_point` reads `elite_flh[slot]`), which is the non-elite one when the elite key is absent |
| `rocket::place` (the spawned rocket missiles of S-0506) | Not raised. These are aircraft-kind objects, not S-0306 projectiles, and claim 8 names only the projectiles it places |
