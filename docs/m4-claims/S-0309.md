# S-0309 target acquisition: claim ledger

Tests: `crates/deterministic/sim/tests/claims_s0309.rs`, which also holds the tests for S-0215
claims 18, 26, 27 and 33 (section at the end). Code: `crates/deterministic/sim/src/combat/acquire.rs`,
plus the search and retaliation hooks in `process.rs`.

Status: **tested**, **partly** (some cases tested, others not modelled), **seam** (the subsystem is
not modelled), **not implemented** (it could be modelled but the code does not do it),
**not testable** (the spec says no setup can show it).
