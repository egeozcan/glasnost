## Departures and edge cases

- Empty metallic debris list: `edge_empty_metallic_list_takes_draws`.
- Debris that can never be placed: `edge_debris_never_placed_stops_after_one_pass`. **Fixed** in `combat::death::deal_debris`: the deal stopped after any full pass that placed nothing. It now stops only when no maximum can give a piece. Found by `f1_voxel_debris_dealt`.
- Empty splash list, missing survivor type, absorbed passengers beyond the last cell: seams.
