## Quirk switches

- `quirks.negative_self_heal_counts`: tested both ways with the spec's example, `quirk_negative_self_heal_counts_on` (3, −2, 0, 5) and `quirk_negative_self_heal_counts_off` (3, 3, 0, 0).
- `quirks.chop_rounding` (owned by S-0205): F1's products are exact for single-precision rates (S-0314 F1), so this file does not test it separately.

## Edge cases

- Periods below one tick: `edge_zero_period_is_one_tick` (P_b = 0 counts as 1 tick).
- Negative interval and negative amount: `edge_negative_interval_and_amount`.
- Building repair step below 1, strength below the repair step, negative step costs, automatic repair with a threshold of 0 or below: seams (building repair, repair steps).
