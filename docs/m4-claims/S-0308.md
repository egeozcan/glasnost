# S-0308 weapon choice: claim ledger

Tests: `crates/deterministic/sim/tests/claims_s0308.rs`. One more test for this spec is in
`claims_s0309.rs` (`zero_mean_damage_is_no_healer`). Code: `crates/deterministic/sim/src/combat/weapon.rs`.

Status: **tested**, **partly** (some cases tested, others not modelled), **seam** (the subsystem is
not modelled), **not implemented** (it could be modelled but the code does not do it), **importer**
(the importer decides it and the simulation only reads the result).
