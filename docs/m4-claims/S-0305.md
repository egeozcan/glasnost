# S-0305 armour classes: claim ledger

Tests are in `crates/deterministic/sim/tests/claims_s0304_s0305.rs`. Code: `glasnost_rules::sim::ArmourClass` (the list, the words, `from_word`), the sim's overlay class in `rules::overlay_rules`, and `WarheadRules::infantry_only`. The importer (`crates/convert`) owns reading the field from the user's files. That covers the trimming of S-0001, the layering (an absent or empty value keeps the class in force, S-0006) and the warnings, and is not tested here.
