## Other edge cases

- Negative turn-rate field: `claim1_negative_turn_rate_uses_the_speed_field`, `claim6a_void_shot`.
- Negative course lock duration: `claim12_negative_course_lock`.
- Cluster count ≤ 0: `claim21_cluster_detonations_and_draws` (cluster 0).
- A steering projectile whose speed reaches 0: `edge_steering_speed_reaches_zero`.
- Effective spawn delay 0 (departure): `edge_spawn_delay_zero_no_trailer`.
- Flak range 0 (departure): `edge_flak_range_zero`.
- Detonation altitude 0: `claim11_vertical_detonation_altitude`.
- Arcing flag on a steering type: `claim6d_arcing_flag_on_a_steering_type`.
- Failed comparison solve (departure): `f4_zero_distance_zero_speed_flatter_shot`.
- Object number of the steering oscillation (departure): `claim13_turn_step_variation_phase` uses our object numbers.
- Lead with a zero shot speed: not tested separately (*u* = 0 under Q-0071 already gives ℓ = 0).
- Ownerless arcing impact: covered by `claim17_firer_killed_projectile_keeps_flying` (detonation as usual).

## Code fixes made while writing these tests

- `claim4_flak_scatter_uses_the_range_of_the_weapon_fired`: *R*_W was always slot 0's range.
- `claim15_cruise_*`: the 18-lepton cruise lift was missing, and the look-ahead cell used P′ + trunc(6 V) instead of P′ + 6 × trunc(V).
- `t1_steering_deck_crossing*`: the steering deck row used the straight row's crossing (20 below the deck going down, and not strict).
- `t1_passed_by_*`: the passed-by row was snapped like a reached row; it is an arrival only for a jumpjet firer.
