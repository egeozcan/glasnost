## Need
S-0606 tables T1 and T2 list 16 and 17 points ending at (0, 0) and say T2 "ends facing 192". S-0207's track rules may stop one point early or apply an end correction; the spec does not say whether the final listed point is itself driven (and so whether the end correction counts it).

## Questions
1. After the release track, is the vehicle exactly at F4 facing 192 (map west)?
2. After an entry track, is it exactly at the reference point, facing the row's track facing, before turning south?

## Current workaround
Interim rule: every listed point is driven, the last included, so the vehicle ends on the track target with the last point's facing.
